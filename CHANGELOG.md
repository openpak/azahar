# Changelog — Azahar (OpenPak fork)

Only OpenPak's changes are listed; everything else is upstream Azahar. `git log` stays the
source of truth. Tags are `vX.Y.Z`; `v*.*.*` publishes a GitHub Release.

## v0.3.4 — 2026-11-04

- openpak-client: `X-OpenPak-Client` names the OS; submodule moved to the rewritten client history
- Android: OpenPak for the 3DS family keeps desktop profile hooks and the signed ceiling
- CI: nightly builds that run only when the source changed, labelled as a label, not a version
- README rewritten for the fork; docs layout standardised

## v0.3.3 — 2026-09-26

- ci: pinned runner image, checkout@v5

## v0.3.0 to v0.3.2 — 2026-09-23 to 2026-09-24

- First OpenPak releases: the connection switch, 3DS family UX, save sync and account pages
